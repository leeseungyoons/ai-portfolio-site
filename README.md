# 이승윤 | ML Engineer 포트폴리오

K-FOOD 해외 수출 AI 플랫폼에서 6인 팀의 AI 파트를 맡았습니다. 5개국의 한국 식품 수출 수요를 예측해 **R² 0.991**을 기록했고, 해외 리뷰 10만 건을 분석해 이진 분류 **F1 0.915**를 달성했습니다. 수출 분석 리포트와 LangGraph 기반 레시피 챗봇도 구현했습니다.

[포트폴리오 보기](https://leeseungyoons.github.io/ai-portfolio-site/) · [GitHub 프로필](https://github.com/leeseungyoons)

## 대표 프로젝트 · K-FOOD 해외 수출 AI 플랫폼

**KT AIVLE School | 2026.01–02 · 8주 · 6인 팀**  
**담당 역할** — 수요예측, 트렌드·리뷰 분석, 리포트, 레시피 챗봇을 포함한 AI 파트 총괄

| 과제 | 구현 내용 | 결과 |
| --- | --- | --- |
| 수출 수요예측 | 미국·일본·중국·베트남·독일의 수출 데이터에 환율·물가지수·산업생산 지표를 결합했습니다. 과거 수출 실적과 이동평균을 변수로 만들고, 직전 값·3개월 이동평균을 기준으로 XGBoost와 LightGBM 등을 비교했습니다. | 3·6·12개월 예측 과제에서 최종 모델 **R² 0.991** |
| 해외 리뷰 분석 | 리뷰 10만 건으로 이진 분류와 다중 등급 예측을 수행했습니다. | 이진 분류 **F1 0.915**, **ROC-AUC 0.961** · 다중 등급 예측 **QWK 0.835** |
| 수출 분석 리포트 | 국가·품목별 분석 결과를 지도, 핵심 지표, SWOT, 알레르기 정보와 함께 정리했습니다. | **13개 섹션**으로 구성된 리포트 |
| 레시피 챗봇 | LangGraph로 SerpAPI 검색부터 레시피 후보 제시까지 연결했습니다. | 검색 결과에 따라 후보를 최대 2개 제시하고, 선택한 레시피를 공개 또는 비공개로 저장 |

## 서비스 개발 및 배포 경험

- **백엔드 API · KT AIVLE 4차 미니프로젝트** — Spring Boot와 Next.js로 구성한 서비스에서 도서 목록 조회·상세 조회·등록 API를 담당했습니다. 데이터 저장에는 JPA와 H2를 사용했습니다.
- **AWS CI/CD · KT AIVLE 5차 미니프로젝트** — AWS CodePipeline으로 CodeBuild의 빌드 단계와 CodeDeploy의 배포 단계를 연결해 EC2의 Nginx 환경에 배포했습니다.
- **스포츠 뉴스 감정분석 · 개인 포트폴리오** — BERT로 스포츠 뉴스의 감정을 분류하고 Streamlit 화면에서 결과를 확인할 수 있도록 구현했습니다. [프로젝트 코드 보기](https://github.com/leeseungyoons/sports-news-sentiment-analysis)
